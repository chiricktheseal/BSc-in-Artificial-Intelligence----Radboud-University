# BSc-in-Artificial-Intelligence----Radboud-University

Welcome to my portfolio repository! This repo contains my **solutions to assignments, projects, and practical work** completed during the **Bachelor of Science in Artificial Intelligence** programme at [Radboud University](https://www.ru.nl/en/education/bachelors/artificial-intelligence) (2023–2026).

## About the Programme
The BSc in AI at Radboud is an interdisciplinary, English-taught programme combining:
- **Computer Science** (programming, algorithms, data structures)
- **Cognitive Neuroscience** (brain, cognition, human-computer interaction)
- **Mathematics & Statistics** (calculus, linear algebra, probability, Bayesian statistics)
- **Machine Learning & Deep Learning** (Neural networks, reinforcement learning, NLP, computer vision)
- **Software Engineering & Ethics** (modern development practices, societal impact)

## Repository Structure
The repository is organised by academic year and course:

- [`2023-2024 -- Year 1/`](./Year-1) – Foundation courses (Programming, Mathematics, Introduction to AI, etc.)
- [`2024-2025 -- Year 2/`](./Year-2) – Core AI topics (Machine Learning, Algorithms, NLP, Deep Learning, etc.)
- [`2025-2026 -- Year 3/`](./Year-3) – Advanced electives and Bachelor's thesis

Each course folder contains my submitted code (Python scripts, Jupyter notebooks, etc.), and sometimes a brief description of the assignment.
